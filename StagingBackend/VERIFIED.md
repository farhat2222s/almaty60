- Зависимости `pg@8.16.3` и `@electric-sql/pglite@0.3.14` установлены; создан `pnpm-lock.yaml` формата 9.0.
- Синтаксис всех серверных файлов и тестов проверен Node.js 24.
- Полный набор `node --test tests/*.test.mjs`: **17 тестов, 17 успешных, 0 ошибок, 0 пропусков**, время прогона **17 900,693569 мс**.
- 4 проверки криптографии и валидации: scrypt, случайные сессии, AES-GCM и отклонение изменённого ciphertext, роли и канонические хеши идемпотентности.
- 13 интеграционных проверок: повторная миграция, регистрация и отзыв сессии, владение попыткой, последовательность и ограничение движения, таймер/поражение, победа и единственная награда, повторные запросы, восстановление новым экземпляром сервиса, staff/brand-границы, погашение/истечение, лимит кампании, Arbat/collect/delivery, блокировка и HTTP auth/body/origin.
- Интеграционные тесты исполнили SQL в настоящем PostgreSQL-движке PGlite/WASM. Его адаптер сериализует транзакции; этот прогон не доказывает поведение нескольких независимых PostgreSQL-подключений под нагрузкой.
- Независимое чтение кода выявило два дефекта, которые исправлены до итогового прогона: повтор транзакций после гарантированного PostgreSQL rollback при deadlock/serialization failure и перечитывание статуса награды при гонке погашения/истечения.

HTTP-часть этого набора вызывает настоящий обработчик запросов без TCP-порта. Дополнительно выполнена следующая проверка запущенного сервера.

## Фактический API на localhost:3080

Запущен `src/local-integration.mjs` на **http://127.0.0.1:3080** с постоянным локальным PGlite-хранилищем. Прямые HTTP-запросы подтвердили **9 проверок**:

1. Readiness отвечает HTTP 200.
2. Запрос без авторизации получает HTTP 401.
3. Регистрация создаёт игрока и действующую сессию.
4. Авторизованный старт Arbat-миссии создаёт серверную попытку.
5. Все пять целей пройдены направляющим вводом с реальной скоростью: движение заняло **9,781 секунды**, без изменения часов или данных БД.
6. Повтор finish с тем же ключом возвращает ту же награду.
7. Игрок не может погасить код через интерфейс сотрудника: HTTP 403.
8. Профиль после победы содержит 150 XP и одну награду.
9. После выхода отозванный токен получает HTTP 401.

Машиночитаемый отчёт: `../docs/validation/live-http.json`. Учётные данные, токены и ключ шифрования в отчёт не включены. В выдаваемом архиве должны отсутствовать `data/`, заполненные `.env` и локальные секреты.

Этот адрес доступен на данном компьютере и **не является опубликованным staging**. PGlite-режим служит локальной интеграционной проверкой; Docker, отдельная PostgreSQL и удалённый TLS-домен остаются отдельным этапом.

## Не выполнено в этой среде

- Docker/Compose и отдельный PostgreSQL daemon отсутствуют: контейнерная сборка, роль `al60_app` на отдельном PostgreSQL, реальные конкурентные подключения и восстановление резервной копии здесь не запускались.
- Не задан и не развёрнут удалённый staging на выделенном сервере с DNS/TLS и постоянной PostgreSQL. Наличие Dockerfile/Compose не означает публикацию.
- Не выполнены нагрузочный тест, внешняя проверка безопасности и подключение реальных партнёрских кодов.
- Этот отчёт не подтверждает сборку или запуск Unreal на iOS/Android.

Все кампании и награды по-прежнему демонстрационные. Проверенные защита доступа и транзакционные ограничения не заменяют серверную физику UE, проверку геолокации, антибот-защиту и коммерческую интеграцию.
