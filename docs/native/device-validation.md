# Журнал нативной проверки

Состояние: не выполнялось. Заполнить после получения первой компилирующейся UE-сборки. Не заменять измерения предполагаемыми цифрами.

| Поле | Результат |
| --- | --- |
| UE version / commit | не проверено |
| Xcode / SDK / NDK / JDK | не проверено |
| Build configuration / device profile | не проверено |
| Телефон / OS / SoC / RAM | не проверено |
| Compile / cook / package | не выполнялось |
| Bootstrap materials / map | не выполнялось |
| 15 минут прогулки / температура | не выполнялось |
| Frame ms median / p95 / p99 | не измерено |
| CPU game / render thread / GPU ms | не измерено |
| Draw calls / triangles / memory peak | не измерено |
| NPC доставка / поиск / прыжки | исходники подготовлены; игровая проверка не выполнялась |
| Автомобиль: посадка / газ / руль / тормоз / задний ход / выход | исходники подготовлены; игровая проверка не выполнялась |
| Автомобиль: стены / поворот у препятствия / заблокированные выходы | статический просмотр sweep/overlap; runtime-проверка не выполнялась |
| Touch joystick + camera + buttons | исходники подготовлены; на телефоне не выполнялось |
| Сервер start / input / win / expiry | native соединение не выполнялось |
| Обрыв сети / повторная отправка / reconnect | native соединение не выполнялось |
| Безопасные области и клавиатура | не выполнялось |

Минимум два реальных профиля: обычный телефон с целью 30 FPS и мощный с целью 60 FPS. Зафиксировать конкретные модели и условия измерений; текущие цели не являются подтверждённой производительностью.
